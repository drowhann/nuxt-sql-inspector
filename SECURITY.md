# Security

## Supported use

**nuxt-sql-inspector** is a development aid. Do not enable it on production or publicly reachable deployments (`forceEnableInProduction` exists only for exceptional local/staging debugging).

When enabled, inspector endpoints have **no authentication**. See the [Security](README.md#security) section in the README.

## Reporting a vulnerability

Please report security issues privately via [GitHub Security Advisories](https://github.com/drowhann/nuxt-sql-inspector/security/advisories/new) for this repository (preferred), or open a private report through GitHub if advisories are unavailable.

Do not file public issues that include exploit details or secrets.

We will acknowledge reports and work on a fix as soon as practical.
